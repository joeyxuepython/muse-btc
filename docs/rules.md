# 当前规则与预警

完整契约见 [SIGNAL_DESIGN.md](../SIGNAL_DESIGN.md)。Phase 1 提供现货动量、现货卖压、杠杆过热和潜在逼空观察规则，以及 BTC 基础风险背景。

当前入场候选要求动量、成交方向、趋势、相对 BTC 强弱、衍生品低过热、价差与 BTC 风险背景同时满足，并检查组件新鲜度与时间对齐。少于三个独立证据组不能升级 STRONG；数据缺失时降级 WATCH。所有新规则保持 OBSERVATION_ONLY，评分不代表成功概率。

OKX/Binance 近期成交样本及按比例推断的现货/合约推动仅为假设。真实清算总量不可用；“潜在逼空”和“去杠杆”都不代表已确认清算。DEX/GoPlus 新规则保持停用，旧提醒归档。

持久化 Web 预警支持已读、未读、固定、解决、过期与升级历史。数字小幅变化更新显示，不重新通知；级别、证据类别或累计评分显著变化记录新事件。通知与声音需在浏览器主动开启，页面关闭后不继续推送。
