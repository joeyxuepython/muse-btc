# Muse 运行指引：BTC 突破过滤研究 v1

分工：Codex 负责研究协议、实现和本地验证；Muse 在云端独立复跑并回传证据。
本次只增加离线研究工具，不重启服务、不修改 `.env`、不连接业务数据库、不开启定时任务。
不要将候选加入入场信号，也不要根据本轮历史结果调整参数后覆盖结果。

## 规则与证据边界

原策略：前一完整 UTC 日收盘价高于 SMA200 时做多 BTC 现货，否则空仓。
新过滤：仅在原策略每段持仓开始时，要求 `close - SMA200 > 0.5 * ATR14`。
ATR14 是最近14个完整日真实波幅的算术平均，包含与前收盘的跳空，不是 Wilder 平滑。
等于门槛不通过。若拒绝，整段原策略持仓都跳过，不在后续某天追入；退出仍按原规则。
分段开始已满足原信号时按边界入场处理并标记，末端平仓为行政退出，不计自然完成样本。

每天 UTC 01:00（北京时间09:00）用小时开盘价作为成交参考，单边费10bp、滑点5bp，另测2倍/4倍成本。
沿用首轮数据 A1 停市延迟与 A2 提前 closeTime 的公开例外，保留缺口记录，不填造价格。
首次协议冻结在本轮过滤版收益计算前；过去的历史已经查看，本轮属于探索，不能声称全新留出检验。
仅一个固定参数，不进行最优参数搜索。2023—2026年度视图是无拟合的时间切片诊断，互相关联。
BTC/现金比较权重只由开发期原策略与持有BTC的波动率确定，此后冻结。
随机对照保留相同的原策略持仓段数，但持仓天数/风险未精确匹配，不能解读为因果证明。
真实成交、最小下单量、盘口滑点与盘中回撤仍未验证。

## 云端命令

使用研究分支 `research/btc-breakout-filter` 的独立检出目录；不切换正在运行服务的检出目录。
将下方示例路径替换为实际的输入目录、全新结果目录。Python >=3.12；不要使用 `-O` 或 `PYTHONOPTIMIZE`。

```bash
git clone --branch research/btc-breakout-filter --single-branch https://github.com/joeyxuepython/muse-btc.git muse-btc-research
cd muse-btc-research/research/breakout_filter
uv sync --locked
uv run --locked python -m unittest discover -v
uv run --locked python run.py --datapack /path/to/btc-trend-research-20261007 --output /path/to/breakout-run1
uv run --locked python verify.py --output /path/to/breakout-run1
```

依赖安装需要网络；研究运行本身离线。输出目录已经存在时拒绝覆盖，失败后也保留现场。
运行约需几十秒至数分钟，取决于CPU；输入复制及交易账本需要数十MB磁盘。
重复运行用全新目录 `breakout-run2`，再次运行 `verify.py`。每次报告都必须通过独立账本核对。
验证工具比对本地参考完整结果（浮点允许极小误差）及代码、文件哈希；通过只代表可复现。
