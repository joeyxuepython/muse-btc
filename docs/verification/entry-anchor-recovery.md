## 已验证的行为

| 场景 | 结果 |
| --- | --- |
| 保存合格旧观测，关闭并重新打开数据库，十分钟后取得合格新观测 | 可复用旧 anchor，PASS；明确报告 600 秒采样/组件源时间断档 |
| 当前 book/candles 已过期 | WAIT，历史 anchor 不能放行 |
| 旧成员只相对当前过期，采集当时新鲜且对齐 | 可以参与确认 |
| 旧成员采集当时已过期、未对齐、源时点或接收时点在未来、质量不合格 | WAIT |
| 默认 anchor 接收年龄 1800 秒 / 1801 秒 | 边界内可确认 / 超界不能确认 |
| 新老 book/candles 源时间差 59 秒 / 60 秒 | 不足确认 / 达到下限 |
| book 或 candles 复用缓存、源时间不变 | WAIT，不能自我确认 |
| 旧、新之间有弱买盘、薄盘口、缺失买入占比或无效输入 | 中间记录参与判定，WAIT，不能跳过寻找有利样本 |
| 独立观测间隔 325 秒 | 合格时 PASS，同时标记断档 |
| 接收间隔未超过 300 秒，但组件源时间最大间隔为 370 秒 | 仍显示 GAPPED，缓存接收不能掩盖源时间断档 |
| 十分钟前弱买盘加当前弱买盘 | 不触发买入支撑消失；取得第二次近期新鲜弱买盘后可触发 |
| 来源不同或决策元数据在未来的旧记录 | 不作为当前 anchor |
| 归档参数 1800 秒，当前配置改为 300 秒 | 回放保留归档的 1800 秒；不同参数产生不同质量/规则版本 |
| 旧归档缺少新参数 | 回放沿用归档 stale_seconds 上限，原始归档 JSON 不改写 |
| 旧归档记录 30 秒确认 | v2 回放仍执行至少 60 秒下限，原始归档 JSON 不改写 |
