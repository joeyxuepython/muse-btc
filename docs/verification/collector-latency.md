## 离线规模实验

使用临时 SQLite 数据库，不连接交易所，不使用用户数据库。生成 121,672 条紧凑快照，102 个资产、120 秒间隔；另加入 721 条各含 180 根 K 线的快照，模拟一天价格路径的 JSON 载荷。总计 122,393 条快照，数据库 296,005,632 字节。K 线载荷仅用于读取成本比较，不是策略效果样本。

在同一个合成库内比较相同窗口的读取，重复五次取中位数；移除/恢复时间索引仅在这个临时库内进行，实验结束删除临时库。

| 操作 | 原方式 | 修复方式 |
| --- | ---: | ---: |
| 全资产最近 300 秒窗口，292 条记录 | 无全局时间索引 39.008 ms | 全局时间索引 2.760 ms |
| 单资产一天路径，721 条记录、每条 180 根 K 线 | 解析完整 Snapshot 393.083 ms | 报价投影 32.274 ms |

`EXPLAIN QUERY PLAN` 确认全局窗口为 `SEARCH snapshots USING INDEX snapshots_time`，不再全表扫描。合成信号的五个到期期限在一个批次中完成，批次耗时 0.046 秒；剩余四个尚未到期任务保留，due_count 为零。

这些数字只代表本机、该合成载荷和缓存条件。没有推算云端的绝对耗时，也没有把读取加速比例当成完整采集轮次的加速比例。
