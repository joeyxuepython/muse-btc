# 后续开发范围

已确认产品目标：辅助实际加密货币买卖决策；BTC、山寨币和 Meme 从首版就同时存在；自动下单暂不开发。原始 V3 文件收到第 17 节开头，后续详细章节尚未收到。

## 首版已实现

真实公开 API 适配器、原始数据留存、质量边界、三个监控模块、BTC 风险联动、中文网页、关注/入场候选/风险/失效记录、去重、前瞻观察、归档重放、配置与测试。

已取得真实 Binance BTC/山寨现货、DEX 池子和 GoPlus 公开检查响应；Binance 合约在线验证仍受云出口地区限制。首版没有经过策略历史有效性验证。

## 下一轮优先工作

1. 放行数据源后验证真实响应、采集周期、时间戳、缺项与限流。
2. 加入 Solana RPC 的 mint/freeze、Token-2022 权限、持仓与流动性风险检查。
3. 接入可靠的新池事件和 DEX 报价新鲜度来源，改善 Meme 发现覆盖，允许满足安全门槛的入场候选。
4. 增加用户观察名单与持仓登记，让退出风险持续覆盖已关注资产，避免仅依赖动态成交量名单。
5. 增加 WebSocket 增量盘口与清算观察，正确恢复断连和订单簿序列。
6. 维护上市/下市、观察名单和缺失区间历史，扩展到更完整的历史回测。
7. 用预先定义的事件标签、时间窗和滚动样本外验证评估规则；只有验证通过的版本进入核心提醒。

## 完整 V3 的后续层

宏观发布/修订与市场反应数据库；BTC 链上公开研究解析；新闻/报告的首次可用时间与证据标注；钱包实体与行为研究；全市场资金轮动和稳定币流动；基于独立证据类别的信号融合；离线权重优化；邮件/Telegram 等独立通知服务；PostgreSQL/对象存储、部署、备份与可观测性。

这些能力在当前程序中显式标记未启用，而不是预填虚构数值。
